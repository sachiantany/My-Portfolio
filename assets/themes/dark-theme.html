02
Flutter Feature Generator — CLI Scaffolding Tool
Personal Project · Born from Litro Gas offline-first implementation

Born while architecting the offline-first sync pipeline for the Litro Gas Sales POS app, this production-grade Dart CLI scaffolds an entire full-stack feature (~25 files) in one command — Clean Architecture + BLoC + Drift SQLite + offline-first sync + Java Spring Boot 3 REST backend. 15 generator modules, 3 CLI modes (interactive, args, init), and idempotent marker-based file merging so re-running never duplicates code.

One command generates ~25 files across the full stack. Auth generation (--auth firebase) wires the complete auth layer across both stacks automatically. Platform-aware ApiConfig auto-selects the correct backend URL for emulator, device, or web — zero manual config.
